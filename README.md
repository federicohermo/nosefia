# Entrada de la noche 2

`noche-2.png` se tomó en Godot 4.7.2, renderizador Compatibility, a 1920 × 991,
con `almacen.tscn` completo: se abrió la primera jornada, se consumió el turno y
se despachó el botón SEGUIR de la placa real del cierre. La captura corresponde
al primer dibujo de la entrada de la segunda jornada; no se modificó la imagen.

La persiana es el PNG original de Figma 567:645 y la placa la dibuja la UI del juego.
