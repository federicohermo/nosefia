# Muestra de la caja en la góndola

Estas dos fotos usan la misma cámara.

- Antes: la caja quedaba suspendida en el aire, delante del apoyo.
- Ahora: el mismo gesto la coloca más al fondo, sobre metal real; queda estable.

La vista frontal tapa el contacto detrás de los productos. Se prepara una vista lateral para mostrarlo claramente. Esta muestra no demuestra una caída ni una entrega terminada de #428.

La decisión de comportamiento sigue abierta: conservar esta colocación sobre apoyo real o cambiar el gesto de ese borde para liberar la caja desde la mano con física. No se eligió ninguna opción por defecto.
